# 2. :computer: 핵심 기능

- 꿈일기를 작성할 수 있습니다.
    - 제목, 내용, 꿈 일자, 공개 여부를 입력합니다.
    - Gemini 기반 꿈일기 감정 분석을 제공합니다.
- 꿈일기에 댓글을 작성할 수 있습니다.
    - 댓글에 대댓글을 작성할 수 있습니다.
- 내가 작성한 꿈일기를 모아서 관리할 수 있습니다.
- 소셜 로그인을 지원합니다.
- 관리자 기능을 지원합니다.
